## 📂 Progetti

### 🚗 AutoFlow — Gestionale per concessionarie auto

**Repository:** [giozoc/AutoFlow](https://github.com/giozoc/AutoFlow)

### 📈 AutoFlow Analytics — Riassortimento intelligente dello stock

Modulo analitico di AutoFlow che simula un dataset di vendite, prevede la domanda con Machine Learning e suggerisce le priorità di riassortimento. Progetto sperimentale sviluppato per il Capitolo 4 della tesi di laurea triennale presso l'Università degli Studi di Salerno, Dipartimento di Informatica.

**Repository:** [giozoc/autoflow-analytics](https://github.com/giozoc/autoflow-analytics)

### 🎨 Tavolo TikZ — Editor visuale per TikZ e pgfplots

Editor visuale che funziona direttamente nel browser e permette di creare e modificare figure TikZ e grafici pgfplots con anteprima immediata. Include modifica visuale degli elementi, editor del codice sincronizzato ed esportazione in TikZ, SVG e PNG.

**🌐 Demo online:** [Apri Tavolo TikZ](https://giozoc.github.io/tavolo-tikz/)  
**💻 Repository:** [giozoc/tavolo-tikz](https://github.com/giozoc/tavolo-tikz)

### 🧮 Tavolo MathTeX — Editor visuale di equazioni matematiche

Editor visuale di formule matematiche in LaTeX, utilizzabile direttamente nel browser. Il codice sorgente e la formula sono sincronizzati in entrambe le direzioni; include una barra di strumenti per simboli e strutture matematiche, anteprima e verifica con MathJax ed esportazione in diversi formati.

**🌐 Demo online:** [Apri Tavolo MathTeX](https://giozoc.github.io/tavolo-mathtex/)  
**💻 Repository:** [giozoc/Tavolo-MathTeX](https://github.com/giozoc/tavolo-mathtex)
